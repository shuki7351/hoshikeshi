# ほしけし 仕様

「動きと操作感」を決めている数値を、ここに集めておく。
見た目を変えるときも、ここにある値は変えないこと（変えると手ざわりが変わる）。

## 画面

- ゲーム画面は 640×800 の固定座標で組み立て、表示時に画面へ収まるよう拡大縮小する（`transform: scale`）。
- 盤面
  - 位置: 左 20px、上 98px
  - 中身の大きさ: 576×660（8列×10段、1マス 72×66）
  - 枠: 12px
- 重なり順（下から）
  1. 盤面
  2. 飾り
  3. リセット
  4. スコア
  5. 操作ブロック
  6. タイトル
  7. スタート
  8. あそびかた
  9. 結果
  10. あそびかた画面

## ルール

- 盤面は横 8 列、高さ 10 段。星は 4 色で、色は毎回ランダム（どの色も同じ確率）。
- 開始時は各列に 5 個ずつ並ぶ。
- 星をタップすると、上下左右につながる同じ色の塊をまとめて選ぶ。
  - 塊が **3 個以上**なら、その場で消える。
  - 2 個以下なら何も起きない（選択状態の表示もない）。
- 得点は「消した個数 × 消した個数」。
- 星が消えたら、その上の星が下へ詰まる。
- 列が空になったら、右側の列が左へ詰まる。
- せり上がり
  - 1 秒ごとに経過秒数を数え、上限を超えたら全列の一番下に 1 個ずつ追加する。
  - 空いていた右端の列も、ここで復活する。
  - 上限は通常 5 秒。スコア 100 超で 3 秒、300 超で 2 秒になる。
  - そのため実際の間隔は、約 6 秒 → 4 秒 → 3 秒になる。
- せり上がった直後に、どこかの列が 10 段を超えていたらゲームオーバー。

## アニメーション

- 動きの緩急はすべて `swing`（`0.5 - cos(πp)/2`）。
- 動くものは、それぞれが順番待ちの列（キュー）を持つ。
  - 動いている最中に次の動きを頼まれても割り込まず、前の動きが終わってから始める。
  - 盤面全体の並べ直しのタイミングも、専用のキューで順番に処理する。

| 場面 | 動き |
|---|---|
| 起動 | 盤面は 500ms 待ってから 200ms でフェードイン。星は盤面の上から 300ms で定位置へ |
| タップで消える | 消える星は手前に出して 300ms でフェードアウト。**500ms 後**に残りの星が 300ms で並び直す（300ms 待ち + 200ms 待ち） |
| せり上がり | 新しい星は盤面のすぐ下（y=660）に出す。1ms 後に全体が 300ms で 1 段上がる |
| スタート | タイトル・スタート・あそびかたが 200ms で消え、スコアとリセットが 200ms で現れる。あそびかた画面が開いていれば 300ms で閉じる |
| あそびかた | 300ms で開き、300ms で閉じる |
| ゲームオーバー | 操作ブロックを半透明の白にして 1000ms でフェードイン。結果は 500ms 待ってから 500ms でフェードイン |

## 操作

| 対象 | 反応するタイミング |
|---|---|
| 星（タッチ） | 指が触れた瞬間（`touchstart`）。`preventDefault` するので、その後の click やズームは起きない |
| 星（マウス） | `click` |
| ボタン | 通常の `click`（指を離したとき） |

- スタート前とゲームオーバー後は、画面全体を覆う操作ブロックで星のタップを止める。
- リセットと「タイトルへ」は、ページを読み込み直さずに、最初の状態から作り直す。

## 追加した機能

- 自己ベストの保存（`localStorage` の `hoshikeshi.best`）。結果画面に表示する。
- スコアのクラウド保存（Firestore）。ログインなし。
  - 端末ごとに12文字のランダムな「きろくID」を作る（32種の文字 = 約60ビット）。
    - このIDが、そのまま「ひきつぎコード」になる。
  - データの場所
    - `players/{ID}`: name, createdAt, plays, best
    - `players/{ID}/scores/{自動ID}`: score, at
  - 書き込みは、スコア追加と回数・ベスト更新を1回の書き込みにまとめて行う。
  - 送れなかったスコアは `localStorage` の送信待ちに残し、起動時や次の保存時に送り直す。
    - スコアの文書IDは送信前に決め、「存在しないときだけ作る」条件付きで送る。二重には記録されない。
  - ルール（`firestore.rules`）の制限
    - 記録はIDを知っている場合だけ読める。一覧取得は禁止。
    - スコアは追加のみ。変更・削除は禁止。
    - プレイヤー情報は、名前の変更と「回数+1」、下がらない「ベスト」だけ許可。

## 検証（2026-09-29, Chrome DevTools）

同じ計測スクリプトを、参照実装と本作の両方で動かして比べた。

| 項目 | 参照実装 | 本作 |
|---|---|---|
| 消える星のフェード | 33→333ms | 0→313ms |
| 残りの星が動き始める | 550ms | 530ms |
| 残りの星が止まる | 850ms | 830ms |
| 落下の進み具合（開始から 50/100/150/200/250ms 後） | .08/.27/.52/.83/.97 | .12/.34/.51/.83/.94 |
| スタートから最初のせり上がりまで | 6019ms | 6027ms |
| せり上がりの移動 | 6052→6336ms | 6061→6361ms |

- 差は 1 フレーム（約 16ms）以内。
- 落下の進み具合の違いは、計測するフレームの位置によるばらつき。
