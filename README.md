# ほしけし

おなじ色の星を3つ以上つなげてタップし、消していくパズルゲームです。
下からせり上がってくる星が、いちばん上まで積み上がったらおしまい。

- スマホ（縦・横）でも PC でも、画面に合わせて全体が表示されます。
- iPhone では Safari の「ホーム画面に追加」で、アプリのように全画面で遊べます。
- なまえを入れると、スコアがクラウド（Firebase）に保存されます。ログインは不要です。
  - 「きろく」で、ベスト10と遊んだ回数を見られます。
  - 「ひきつぎコード」を控えておけば、機種変更しても記録を引き継げます。
  - 保存した記録は、だれにも（本人にも）消したり書き換えたりできません。

## 遊び方（ローカル）

`index.html` をブラウザで開けば遊べます。

## 構成

```
index.html
css/style.css
js/anim.js     アニメーションキュー（緩急と順番待ち）
js/game.js     ルール（盤面・消去・せり上がり・得点）
js/cloud.js    スコアのクラウド保存（Firestore REST API）
js/main.js     表示と操作、画面サイズへの拡大縮小
img/*.svg      星・マス・飾りの画像（すべて自作）
docs/spec.md   動きと操作感を決める数値の仕様
firestore.rules  データベースのルール（書き足しのみ・削除禁止）
tools/bump-version.js  公開前に画像・CSS・JS の参照の版（?v=）を更新する
```

## 更新して公開するとき

GitHub Pages はファイルを10分間キャッシュさせる設定で配信します。
そのため、画像や CSS の参照に版（`?v=…`）を付けて、更新がすぐ反映されるようにしています。

公開（push）の前に、次を実行してください。

```bash
node tools/bump-version.js
```

- 外部ライブラリは使っていません。
