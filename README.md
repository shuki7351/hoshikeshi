# ほしけし

おなじ色の星を3つ以上つなげてタップし、消していくパズルゲームです。
下からせり上がってくる星が、いちばん上まで積み上がったらおしまい。

- スマホ（縦・横）でも PC でも、画面に合わせて全体が表示されます。
- iPhone では Safari の「ホーム画面に追加」で、アプリのように全画面で遊べます。
- 自己ベストはブラウザに保存されます。

## 遊び方（ローカル）

`index.html` をブラウザで開けば遊べます。

## 構成

```
index.html
css/style.css
js/anim.js     アニメーションキュー（緩急と順番待ち）
js/game.js     ルール（盤面・消去・せり上がり・得点）
js/main.js     表示と操作、画面サイズへの拡大縮小
img/*.svg      星・マス・飾りの画像（すべて自作）
docs/spec.md   動きと操作感を決める数値の仕様
```

- 外部ライブラリは使っていません。
